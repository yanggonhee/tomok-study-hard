토목기사 실기 · iPhone PWA · 오늘 15 + 누적복습

[학습 규칙]
- 오늘 집중학습은 최대 15문항입니다.
- 전날 못 외운 문제를 먼저 유지하고, 비는 자리만 신규 문제로 채웁니다.
- 신규 문제 15개 기준: 2008~2020년 13개 + 2021~2026년 2개 순환.
- 오늘 암기 완료한 문제는 다음날부터 누적복습으로 붙습니다.
  예: 첫날 15개 중 5개 암기 → 다음날 집중 15 + 누적복습 5 = 총 20개.
- 탈탈 378문항은 기존 메뉴에서 별도로 학습합니다.

[GitHub Pages]
- 이 폴더의 파일을 저장소 루트에 올립니다.
- GitHub Settings > Pages에서 배포 브랜치를 선택합니다.
- 아이폰 Safari에서 Pages 주소를 연 뒤 공유 > 홈 화면에 추가를 누릅니다.
- 홈 화면 앱 안에서 「오늘 15」을 누르면 오늘 학습을 시작합니다.

[회사 PC와 연동]
1. Supabase에서 프로젝트를 만들고 supabase_setup.sql을 SQL Editor에서 한 번 실행합니다.
2. Project URL과 anon public key를 sync-config.js에 넣습니다. 이 두 값은 웹 공개용 값입니다.
3. 아이폰 웹에서 「연동」 버튼을 누릅니다.
4. 자동 생성된 연동코드를 저장합니다. 이 코드는 iPhone localStorage에만 저장되며 GitHub에는 올라가지 않습니다.
5. 회사 PC의 sync_config.json에 같은 URL / anonKey / syncCode를 입력합니다.
6. 이후 암기상태·애매칸·오늘15 계획·누적복습이 서로 합쳐집니다.

Supabase 값이 비어 있어도 웹 학습서는 로컬 저장으로 정상 작동합니다.
